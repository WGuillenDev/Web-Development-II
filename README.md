## 📖 Sobre este portafolio

Este repositorio reúne las prácticas, laboratorios, investigaciones y proyectos desarrollados durante el curso **Programación en Ambiente Web II**, curso de 6 créditos, nivel VI de la carrera. Es la continuación de [Portafolio Web I](https://github.com/WGuillenDev/Portafolio-ISW-521).

El curso busca desarrollar la habilidad para construir servicios web con lenguajes del lado del servidor, aplicando modelos de persistencia, patrones de arquitectura y diseño, y técnicas de seguridad, cubriendo desde los fundamentos de los marcos de trabajo (frameworks) hasta la configuración y publicación de servicios web en su entorno de ejecución.

**Ejes del curso:** servicios web y frameworks · persistencia y ORM · APIs · comunicación cliente-servidor · seguridad con tokens · despliegue.
